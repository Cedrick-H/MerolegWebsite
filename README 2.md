# Printing House Website (Homepage - Phase 1)

React + Vite + Lucide icons, Montserrat font, brand palette: green #51ba71, deep green #284e27, black #231f20.

## Run locally
1. Install Node.js LTS from https://nodejs.org (check with `node -v`).
2. Open this folder in VS Code (File > Open Folder).
3. Open the terminal (Ctrl+`) and run:
   npm install
   npm run dev
4. Open the http://localhost:5173 link shown in the terminal.

Build for production: `npm run build` (output in /dist).

## Edit your details
src/data/site.js holds phone, WhatsApp number, email, address, hours, services, projects and testimonials.
